## What this is not

Palmistry is folklore. It is not a science. It does not predict the future. A report from this desk is a literary reading of creases in skin, written as craft, not as fact.

The length of a life line is not a lifespan. This desk does not read death, disease, fertility, court results, lottery numbers, or investment returns.
